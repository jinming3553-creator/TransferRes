# TransferRes 1.0.0

First stable release of **TransferRes — Transferable Perturbational Resolution**.

TransferRes estimates the hierarchy level at which perturbational response
patterns transfer across independent biological units using leakage-aware
held-out prediction.

### Release validation

- Windows standalone build: PASS
- Packaged EXE self-test: PASS
- GUI / HTML / path robustness acceptance: PASS
- Whole-brain Glut Broad→Class manuscript reproduction: **14/14 PASS**

The v1.0.0 estimator and interpretation contract are frozen. See
`RELEASE_NOTES_v1.0.0.md` and `REPRODUCIBILITY.md` for the statistical contract
and acceptance history.
